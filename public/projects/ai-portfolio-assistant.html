AI-Driven Portfolio ChatbotA grounded chatbot with human escalation

A portfolio chatbot designed to answer questions about my professional background from structured resume data, while handing off questions that fall outside its supported scope.

Built as a personal project · workflow-based automation
Design objective
Keep the model's factual context narrow, make the response path explicit, and provide a human fallback when the agent should not answer on its own.
01 / System

Two workflows, one job

The first workflow turns structured resume data into a single modular prompt. The second uses that prompt to operate the chatbot, keep a full QA record of every interaction, decide whether the request is within scope, and escalate when it is not.

01

Build context

Read the maintained resume modules and normalize their contents.

02

Assemble prompt

Turn the normalized data into one controlled text context.

03

Run agent

Give the agent the prompt, user query, models, memory and output parser.

04

Log & check scope

Keep the full interaction in Google Sheets, then route it through a switch.

05

Answer or escalate

Return the answer to the portfolio or hand the conversation to the owner.

The design principle The chatbot is not intended to answer everything. It is intended to answer what its supplied context can support, and to stop pretending when it cannot.
02 / Context construction

The resume is data first.

The source material lives in spreadsheet modules rather than inside a fixed prompt. Code and field-mapping steps collect the rows, normalize them into lists, and turn the result into one text prompt for the agent.

Why externalize it?

Updating the source data updates the chatbot's context. The resume does not need to be rewritten as prompt text every time something changes.

Why constrain the context?

LLMs can produce plausible information that is not actually supported. Narrowing the factual source reduces the opportunity for unsupported claims and makes the agent's intended scope explicit.

03 / Agent

Then the prompt becomes the agent's working context.

The assembled prompt feeds an AI Agent. The agent uses the supplied context alongside its configured models, memory and structured output parser. The full interaction is logged for QA regardless of the outcome. The workflow then decides what to do with the request.

AI agent and routing workflow

The second half of the system is where the chatbot becomes operational: answer the request when it is supported, otherwise create a human handoff.

or

Too complex / outside scope

The query cannot be safely handled from the supplied context.

  • Retrieve the user's details, or ask for them if they are missing.
  • Tell the user the concern has been forwarded.
  • Send the conversation summary and user details to the owner.
04 / Human fallback

The failure case is a workflow, not an error.

When the agent cannot handle the question, the system does not force a speculative answer. It turns the conversation into a handoff with enough context for the owner to act.

01

Collect user info

Once the issue is outside scope, the agent retrieves the user's name, contact number and email, or asks for them if they are not available.

02

Acknowledge

The user receives an automatic reply explaining that the concern has been forwarded to the owner.

03

Notify the owner

A conversation summary and relevant user information are sent by email and Telegram.

04

Keep the transcript

Every interaction is recorded in Google Sheets, regardless of outcome, so the full transcript can be retrieved for QA and review.

06 / Design principle

Keeping the bot accountable.

The automation can handle the conversation, but I still need visibility into what it is telling people.

I need to be aware of what the bot is telling people.

Every interaction is recorded in full, including conversations the bot handles successfully. That gives me a way to review exactly what was said, check that it stayed within the information provided, and spot anything that needs to be corrected.

The automation handles the conversation. I remain responsible for what it says.
